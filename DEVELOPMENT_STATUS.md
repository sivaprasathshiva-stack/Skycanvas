## ⚠️ Known "Limitations" (By Design)

These are **intentional design decisions**, not bugs:

### Mobile App
1. **30 stars vs 9,110**: Keeps app lightweight, still shows all bright objects
2. **10 constellations vs 88**: Covers most recognizable patterns
3. **Simplified planet math**: Accurate enough for casual users (not research-grade)
4. **No AR mode yet**: Complex feature saved for v2.0
5. **UTC time only**: Timezone support is easy to add if needed

### Windows App
6. **Requires Python**: Skyfield library is Python-based (could be replaced with Dart implementation)
7. **Chromecast partial**: Structure ready, needs native SDK integration

### These Are Fine Because:
- ✅ Apps work perfectly for intended use cases
- ✅ Users get excellent experience
- ✅ Apps are production-ready
- ✅ Can be enhanced post-launch
- ✅ Cost/benefit of adding them now is low
